# ENDURE Marketing Site

Marketing site for the ENDURE indoor cycling app. This context covers the language used in site copy (EN/DE) — not the app's internal domain.

## Language

**Zwift Click**:
A handlebar remote ENDURE pairs over Bluetooth. Click v1 is the verified generation and the only one copy claims; v2 is described as untested rather than as working or unsupported.
_Avoid_: Controller; claiming v2 support; claiming v1 and v2 behave identically

**Virtual Shifting**:
ENDURE's name for changing effort from the handlebar with a Zwift Click — the ERG target inside a structured workout, trainer resistance in SIM mode. It is *not* gear simulation: ENDURE does not model a cassette or gear ratios, and no gear number is shown. Because Zwift's feature of the same name does simulate gears (Cog + Click), every page using the term states plainly what ENDURE's buttons actually change. Stays English in German copy.
_Avoid_: Virtuelles Schalten; simulated gears, gear lever, gear ratios, cassette simulation; implying a drivetrain is modelled

**SIM mode**:
The riding mode in which trainer resistance is set directly, as opposed to ERG mode where the trainer holds a target wattage. The mode a Zwift Click's resistance steps apply to.
_Avoid_: Simulation mode spelled out, gradient mode

**Sensor pairing**:
Connecting a device to ENDURE over Bluetooth, the same flow for all devices (trainers, power meters, HR monitors, CORE, Zwift Click).
_Avoid_: Setup, installation

**Pricing phase**:
The app is currently free; an affordable subscription is planned. Copy states this directly without a phase label.
_Avoid_: Early Release, Early Access, Beta (retired July 2026 — the app is released on iOS & Android)

**Smart Trainer**:
A trainer whose resistance ENDURE can control over Bluetooth (ERG mode). The term used throughout feature copy in both languages.
_Avoid_: Rollentrainer as a synonym — see below

**FTMS**:
Fitness Machine Service — the Bluetooth standard ENDURE uses to control trainer resistance. Named explicitly in copy where trainer compatibility is discussed. ENDURE connects over Bluetooth only; ANT+ is not supported and is stated as such rather than left open.
_Avoid_: ANT+ FE-C as a supported path

**Rollentrainer** (DE only):
German umbrella term covering all trainers, including non-controllable ones. Used only in DE SEO slots (title, meta description, hero H2, FAQ question) because it is the term German riders search with. Never used in feature copy as a substitute for Smart Trainer, and the boundary is stated explicitly in the FAQ: ERG control requires a Smart Trainer; a non-controllable trainer can still be recorded via power meter or HR sensor.
_Avoid_: Using it to describe ERG-capable hardware

**Free Ride**:
Riding without a structured workout; resistance is controlled manually (optionally in ERG mode by watts).
_Avoid_: Just ride, manual mode

**ERG mode**:
The state in which ENDURE holds a target wattage by steering trainer resistance. Written "ERG mode" / "ERG-Modus" — capitalised, never expanded.
_Avoid_: Erg, erg-mode, automatic mode

**LT1 / LT2**:
The two lactate thresholds ENDURE estimates from logged readings. Always written as the abbreviation with the physiological name on first use in a page ("LT1, the aerobic threshold"). Kept as LT1/LT2 in German copy.
_Avoid_: Aerobic/anaerobic threshold alone, MLSS as a synonym for LT2

**Heat Zone**:
A training range derived from CORE body temperature, the thermal equivalent of a power zone. Stays English in German copy ("Heat Zones"), because that is how the concept is named in the app.
_Avoid_: Hitzezone, temperature zone

**Climbing Efficiency**:
ENDURE's VAM-based score for how effectively a rider converts watts into vertical metres, computed from automatically detected climbs in outdoor rides. Stays English in German copy.
_Avoid_: Kletter-Effizienz, climb score
